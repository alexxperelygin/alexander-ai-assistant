# Capital OS

Агент-оператор, который превращает исследования в проверяемые ставки: база из 210
результатов в двух слоях → рейтинг возможностей → модель Монте-Карло → замороженные
эксперименты → недельный план. Последний отчёт: [`status/capital-os.md`](../status/capital-os.md).

## Что он говорит прямо сейчас

- Вероятность $1 млрд чистого капитала за 15 лет — около 0,7% при лучшей из пяти
  стратегий (кэш-двигатель плюс серия продуктовых компаний с долей). Скупка сервисных
  фирм — 0,45%, фонд — 0,05%, торговля собственным счётом и инфобизнес — 0%.
- Это число получено из допущений в `data/model.json`, а не из измерений. Оно полезно
  порядком величины и тем, какие рычаги его двигают: темп роста компании, скорость
  вердикта по продукту, доля владельца.
- В реестре 26 возможностей; 14 найдены исследованием рынка без привязки к текущим
  проектам владельца. Лучший вариант с хвостом — агент под ключ для одной запущенной ниши
  услуг с оплатой за результат.
- Первое по ожидаемой ценности действие — реструктуризация долга, второе — платная
  подписка на базе канала: они дешёвые и быстрые, поэтому остаются кэш-двигателем.

Подробно: [`docs/THESIS.md`](docs/THESIS.md), план на 90 дней — [`docs/PLAYBOOK_90D.md`](docs/PLAYBOOK_90D.md).

## Запуск

```bash
cd capital-os
pip install -r requirements.txt
python -m pytest -q tests                # 13 тестов
python -m capital_os cycle               # полный цикл, отчёт в status/capital-os.md
python -m capital_os rank                # рейтинг возможностей
python -m capital_os simulate --sensitivity
python -m capital_os kb кредитор         # поиск по базе исследований
python -m capital_os gate "текст поста"  # проверка текста перед публикацией
python -m capital_os freeze risk-desk-sub --start 2026-12-01
python -m capital_os verdict
```

Слой рассуждения включается переменной `ANTHROPIC_API_KEY` (модель `claude-fable-5-2`,
меняется через `CAPITAL_OS_MODEL`). Без ключа цикл идёт детерминированно: числа те же,
вместо плана модели — следующие шаги экспериментов.

## Устройство

| файл | что делает |
|---|---|
| `kb/research.json` | классика: 16 областей по 10 результатов; у каждого правило для агента |
| `kb/frontier.json` | слой 2025–2026 со ссылками: базовые частоты, агенты, маршруты, секторы, наука |
| `data/opportunities.json` | 26 возможностей: оценки, референсный класс, эксперимент, критерий закрытия |
| `data/model.json` | допущения Монте-Карло и распределения ресурсов |
| `capital_os/scoring.py` | стягивание оценок к базовой частоте, ожидаемая ценность, штанга 70/30 |
| `capital_os/montecarlo.py` | пять стратегий, горизонты 10 и 15 лет, чувствительность |
| `capital_os/experiments.py` | заморозка критериев хэшем, вердикты PASS / FAIL / KILL |
| `capital_os/compliance.py` | шлюз: блокирует обещания доходности, отправляет деньги и подписи на подтверждение |
| `capital_os/llm.py` | запрос к модели со строгой схемой плана |
| `capital_os/agent.py` | цикл и отчёт |
| `state/journal.jsonl` | память: узкое место, вердикты и разбор каждого цикла |

## Как вносить данные

Результаты экспериментов записываются в `data/observations.json`:

```json
{"risk-desk-sub": {"value": 212, "sample": 16000}}
```

Оценки в `data/opportunities.json` правит владелец; модель может только предложить правку
в отчёте. Замороженный эксперимент переписать нельзя: изменённые критерии дают вердикт
`TAMPERED`.

## Границы автономии

Агент сам исследует, считает, пишет черновики и документы. Расход денег, подпись,
рассылка, публикация от имени владельца, обращение к кредитору, приём чужих средств и
торговля реальными деньгами идут в очередь на подтверждение. Гарантии доходности,
сигналы по неликвидным активам и новый долг для закрытия старого запрещены в коде.

## Чего здесь нет

- Слой рассуждения с настоящим ключом не запускался: запрос проверен до ответа сервера
  об авторизации, ответ модели по схеме не проверен.
- Интеграций с Telegram, платежами и биржами нет. Наблюдения вносятся вручную.
- Числа классического слоя записаны по памяти о публикациях; числа слоя 2025–2026 взяты
  в основном из поисковых сводок. Перед решением или цитированием сверять по ссылке.
- Оценки возможностей — стартовые суждения, ни одна не измерена.
