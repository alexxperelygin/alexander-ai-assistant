# Product Spec — MemeScope AI

## Цель

Непрерывно анализировать рынок новых мем-коинов Solana, выявлять потенциально сильные
монеты раньше основной фазы роста и давать пользователю объяснимый торговый план.
Реальные сделки исполняет только пользователь; система формирует рекомендации,
paper-сделки и сопровождение. Seed-фразы и приватные ключи никогда не запрашиваются.

Главная бизнес-цель — найти повторяемое положительное математическое ожидание после
всех издержек. Если исследования его не подтверждают, система показывает **NO EDGE**.

## Пользовательский сценарий

1. Worker 24/7 обнаруживает новые пулы и оценивает токены.
2. На Overview/Scanner пользователь видит поток возможностей со score и статусами.
3. При статусе READY приходит уведомление; на странице Opportunity — полное объяснение:
   почему монета интересна, какие риски, где купить, размер позиции, slippage-лимит,
   invalidation, стоп, уровни фиксации, срок действия сигнала.
4. Пользователь либо открывает paper-позицию, либо покупает вручную и жмёт "I bought".
5. Система мониторит позицию: стопы, TP-лестница, отток ликвидности, уведомления,
   P&L, полный audit trail.
6. Backtests и Signal History показывают измеренное качество алгоритма.

## Ответ системы на 9 вопросов пользователя

| Вопрос | Где отвечает система |
| --- | --- |
| Какая монета | Opportunity: тикер, mint, ссылки на DexScreener/RugCheck/Solscan |
| Почему | Причины сигнала + разбивка score с формулами |
| Где купить | Инструкция Jupiter + прямая ссылка на своп |
| Размер позиции | План: из капитала, риска на сделку и % ликвидности пула |
| Риски | Флаги RugCheck + rejections + risk-компоненты score |
| Отмена входа | Invalidation conditions в плане |
| Фиксация прибыли | TP-лестница 1.5x/2x/4x (настраивается) |
| Полное закрытие | Stop/полный выход + аварийный выход при оттоке ликвидности |
| Пересмотр после входа | Мониторинг каждые 30с, события и уведомления |

## Статусы сигнала

WATCH, CANDIDATE, READY, BUY, HOLD, TAKE_PROFIT, EXIT, INVALIDATED, AVOID,
DATA_UNAVAILABLE — переходы записываются в SignalEvent с причиной.

## Критерии готовности MVP (финальный тест)

- [x] 24/7 воркер получает реальные данные о новых токенах Solana без API-ключей
- [x] Отбраковка опасных/неликвидных активов hard-rejection правилами
- [x] Прозрачное ранжирование остальных (каждый балл объясним и воспроизводим)
- [x] Объяснимый paper-сигнал с планом входа и выхода
- [x] Сопровождение позиции с P&L и audit trail
- [x] Статистика качества на dashboard (Backtests, Signal History)
- [x] Ошибки источников видны в System Health
- [x] Typecheck, production build и тесты проходят
- [ ] Подтверждённый out-of-sample edge — **не достигнут и не заявляется**; требуется
      накопление данных (см. BACKTEST_METHODOLOGY)

## Вне охвата первой версии (см. ROADMAP)

Автоисполнение сделок, другие сети (Base/Ethereum/BNB — архитектура готова через
адаптеры), полноценный социальный анализ, кластеризация кошельков on-chain, ML-модели.
