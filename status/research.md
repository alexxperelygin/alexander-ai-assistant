## 4. Правила отбора (6h)

Соцданные (X) привязаны к 50 569 наблюдениям —
последний замер не позже наблюдения и не старше 2 часов. Если это число мало,
строки про X ничего не доказывают: отсутствие данных не равно отсутствию связи.

**Coverage** — доля наблюдений правила с измеримым исходом. Если у правила
coverage сильно выше базовой линии, его результат завышен выживаемостью:
измеряются только «дожившие» токены. Это главный риск ложного edge.

Дополнительно снимаются две методические ловушки:
* **дедупликация по токенам** — пампящий токен даёт десятки наблюдений подряд,
  и все они «выигрышные»; это раздувает мнимое преимущество. Берётся первое
  подходящее наблюдение на токен, то есть одна сделка = один токен;
* **train/test по времени** — правила подбираются на первых 70% окна,
  проверяются на последних 30%. Если на test преимущество исчезает — это была подгонка.

### 4e. Контрольные группы: это отбор или артефакт измерения

Положительное среднее выше само по себе ничего не доказывает. Ровно та же
процедура запускается здесь с изменённым ОДНИМ условием: если результат не
меняется, значит найденное правило ни при чём.

**Контроль 1 — без фильтра по ликвидности.** Те же выходы, вход в любой
токен (2812 сделок из 3084 входов).
